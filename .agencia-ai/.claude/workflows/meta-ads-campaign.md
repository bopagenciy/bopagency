# Workflow: Meta Ads Campaign

## Descripción
Proceso completo para crear, lanzar y optimizar una campaña de Facebook e Instagram Ads.

---

## FASE 1: BRIEFING Y ESTRATEGIA

### Paso 1: Definir Objetivo
- [ ] Objetivo de negocio (¿qué quiere lograr el cliente?)
- [ ] Objetivo de Meta (Leads / Ventas / Tráfico / Reconocimiento / Engagement)
- [ ] KPI principal y target (ej: CPL objetivo < $X)

### Paso 2: Definir Audiencia
- [ ] Demografía (edad, género, ubicación)
- [ ] Intereses principales (3-5 categorías)
- [ ] Comportamientos (si aplica)
- [ ] ¿Tiene datos propios? (email list, pixel, CRM)
- [ ] Estrategia de lookalike audience
- [ ] Estrategia de retargeting

### Paso 3: Presupuesto y Período
- [ ] Presupuesto diario o total
- [ ] Fechas de la campaña
- [ ] Distribución por ad set

---

## FASE 2: CREACIÓN DE CAMPAÑA

### Paso 4: Crear Estructura
Usar skill `meta-ads-campaign-builder`:
- [ ] Campaña creada con nombre claro [Cliente_Objetivo_Mes]
- [ ] Ad sets definidos (frío / retargeting)
- [ ] Optimización de cada ad set configurada

### Paso 5: Crear Copy de Anuncios
Usar agente `copywriter`:
- [ ] Hook (primera línea que detiene el scroll)
- [ ] Copy principal (PAS o AIDA)
- [ ] Headline del anuncio
- [ ] CTA
- [ ] Mínimo 2 variantes por ad set (A/B test)

### Paso 6: Definir Creatividades
Usar agente `creative-director`:
- [ ] Formato por anuncio (imagen / video / carrusel)
- [ ] Descripción visual para el diseñador
- [ ] Prompt de imagen si se usa IA
- [ ] Specs por placement (Feed, Stories, Reels)

### Paso 7: Revisar Compliance
Usar skill `meta-ads-compliance-review`:
- [ ] Revisar todo el copy
- [ ] Revisar creatividades descritas
- [ ] Revisar landing page de destino
- [ ] Verificar si aplica categoría especial

---

## FASE 3: ENTREGABLE PARA EL CLIENTE

### Paso 8: Crear Documento de Campaña
- [ ] Estructura completa documentada
- [ ] Copy aprobado
- [ ] Sugerencias visuales
- [ ] KPIs y período de evaluación
- [ ] Compliance notes

### Paso 9: Presentación y Aprobación
- [ ] Enviar al cliente para revisión
- [ ] Incorporar feedback
- [ ] Aprobación final

---

## FASE 4: POST-LANZAMIENTO

### Paso 10: Plan de Optimización
- [ ] Revisar primeras 48-72h: entrega y alcance
- [ ] Semana 1: Evaluar CTR y CPL inicial
- [ ] Semana 2: Pausar anuncios de bajo rendimiento
- [ ] Semana 3-4: Escalar lo que funciona, testear nuevas variables

## Agentes Involucrados
- meta-ads-specialist (líder)
- copywriter (copy)
- creative-director (creatividades)
- compliance-reviewer (revisión)
- analytics-reporting-specialist (seguimiento)
