# Skill: SEO Content Brief

## Descripción
Crea briefs completos para contenido SEO: keyword principal, intención de búsqueda, estructura del artículo, palabras clave relacionadas, y guías para el escritor.

## Parámetros de Entrada
- Keyword principal objetivo
- URL del website del cliente
- Industria y audiencia del cliente
- Objetivo del contenido (posicionar / educar / convertir)

## Formato de Salida

```
## SEO CONTENT BRIEF

**Keyword Principal:** [keyword]
**URL Objetivo:** [/slug-del-articulo]
**Intención de Búsqueda:** [Informacional / Navegacional / Transaccional / Comercial]
**Volumen de Búsqueda Estimado:** [X/mes]
**Dificultad:** [Alta/Media/Baja]

### META TAGS
- **Title Tag:** [60 chars max con keyword]
- **Meta Description:** [155 chars max con CTA]
- **H1:** [Título del artículo — diferente al title tag]

### PALABRAS CLAVE RELACIONADAS
- Secundarias: [keyword 2, keyword 3, keyword 4]
- LSI Keywords: [término relacionado 1, 2, 3]
- Preguntas que responde: [¿Cómo...? ¿Qué es...? ¿Cuánto...?]

### ESTRUCTURA DEL ARTÍCULO
**Longitud objetivo:** [1200 / 1800 / 2500 palabras]

H1: [Título principal]
  H2: [Sección 1 — incluye keyword secundaria]
    H3: [Subsección]
  H2: [Sección 2]
    H3: [Subsección]
  H2: FAQ — [Preguntas frecuentes]
  H2: Conclusión + CTA

### INSTRUCCIONES PARA EL ESCRITOR
- Incluir keyword principal en: H1, primer párrafo, al menos 2 H2, conclusión
- Densidad de keyword: 1-2%
- Incluir estadísticas con fuente
- Agregar 2-3 imágenes con alt text
- Enlazar a X páginas internas
- Incluir CTA al final

### COMPETIDORES A SUPERAR
- [URL competidor 1] — [Por qué está rankeando]
- [URL competidor 2]

### SCHEMA RECOMENDADO
- Article Schema
- FAQ Schema (si incluye FAQ)
```
