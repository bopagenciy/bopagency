# Workflow: Content Calendar

## Descripción
Proceso para crear un calendario de contenido mensual estratégico y ejecutable para redes sociales.

---

## PASO 1: Revisar Contexto del Cliente
- [ ] Cargar brand profile del cliente
- [ ] Revisar objetivos del mes
- [ ] Verificar fechas especiales (lanzamientos, promociones, eventos)
- [ ] Revisar qué funcionó el mes anterior (si aplica)

## PASO 2: Definir Pilares de Contenido
Establecer 4-5 pilares para el mes:
1. Educativo: [Temas específicos relacionados al servicio]
2. Inspiracional: [Temas que generen emoción y conexión]
3. Entretenimiento/Relatable: [Contenido liviano]
4. Prueba Social: [Testimonios, casos de éxito, behind the scenes]
5. Conversión: [CTAs directos, ofertas, servicios]

## PASO 3: Definir Mix de Contenido
Por plataforma, establecer:
- Frecuencia (posts por semana)
- Formatos (% de reels vs. carrusel vs. estático vs. stories)
- Horarios óptimos de publicación

## PASO 4: Crear Ideas por Semana

**Para cada semana, crear:**
- 2-3 ideas de contenido educativo
- 1-2 ideas de entretenimiento/relatable
- 1 idea de prueba social
- 1 contenido de conversión (cada 4-5 posts)
- Ideas de stories complementarias

## PASO 5: Crear Hooks para cada Post
Para cada idea:
- Versión A: Hook de curiosidad
- Versión B: Hook de dolor/problema
- Versión C: Hook de número/beneficio

## PASO 6: Crear Captions
Usar skill `caption-generator`:
- Caption completo para cada post
- Adaptado a la plataforma
- Con la voz de marca del cliente

## PASO 7: Definir Hashtags
- Set general del nicho (15-20 hashtags)
- Set de nicho específico (8-12 hashtags)
- Hashtags propios de marca (2-3)
- Combinar para cada post

## PASO 8: Sugerencias Visuales
Para cada post:
- Descripción de lo que debe mostrar la imagen/video
- Paleta de colores
- Estilo fotográfico o de diseño
- Texto que va en el visual (si aplica)

## PASO 9: CTAs del Mes
Definir los CTAs principales del mes:
- CTA de conversión principal (ej: "Agenda tu consulta")
- CTAs de engagement (ej: "Comenta abajo")
- CTAs de shares/guardados (para contenido educativo)

---

## ENTREGABLE FINAL
Tabla o documento con:
- Semana y fecha
- Plataforma
- Pilar de contenido
- Formato
- Idea/tema
- Hook
- Caption
- Hashtags
- Idea visual
- CTA

## Agentes Involucrados
- content-strategist (líder)
- copywriter (hooks y captions)
- creative-director (ideas visuales)
