# Skill: Brand Audit

## Descripción
Auditoría completa de marca que evalúa posicionamiento, voz, mensajes, diferenciadores y consistencia de comunicación.

## Cuándo Usar
- Al iniciar con un nuevo cliente
- Cuando la marca necesita refresh o reposicionamiento
- Antes de crear campañas para asegurar consistencia
- Cuando hay inconsistencias en la comunicación

## Parámetros de Entrada
- URL del website del cliente
- Perfiles en redes sociales
- Materiales de marca existentes (opcional)
- Propuesta de valor autopercibida del cliente

## Proceso

1. Revisar website: homepage, about, servicios/productos
2. Analizar redes sociales: tono, consistencia, engagement
3. Evaluar propuesta de valor: claridad y diferenciación
4. Identificar mensajes clave actuales
5. Comparar con posicionamiento deseado
6. Evaluar consistencia verbal y visual
7. Identificar gaps y oportunidades

```
**Fecha:** [Fecha]

### 1. Resumen Ejecutivo
[3-5 hallazgos más importantes]

- **Tono de comunicación:**
- **Mensajes principales:**
- **Consistencia general:** [Alta / Media / Baja]

### 3. Análisis de Website
- Claridad del mensaje: [1-10]
- Propuesta de valor above-the-fold: [Sí/No]
- CTAs: [Análisis]

### 4. Análisis de Redes Sociales
- Consistencia con el website: [Alta/Media/Baja]
- Tono: [Descripción]
- Top contenido: [Tipos]
- Gaps detectados: [Lista]

### 5. Diferenciadores
- **Lo que hace bien:**
- **Oportunidades de diferenciación:**
- **Competencia directa:**

### 6. Recomendaciones
1. [Recomendación prioritaria 1]
2. [Recomendación prioritaria 2]
3. [Recomendación prioritaria 3]
```
