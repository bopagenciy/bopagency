# Comando: /create-email-sequence

## Descripción
Crea una secuencia completa de emails para cualquier objetivo.

## Uso
```
/create-email-sequence
/create-email-sequence tipo=[welcome/nurturing/lanzamiento/reactivacion] cantidad=[5]
```

## Instrucción para Claude
Actúa como `email-marketing-specialist`. Usa la skill `email-sequence-builder`. Crear subject lines, preview text y copy completo de cada email con el intervalo de envío recomendado.
