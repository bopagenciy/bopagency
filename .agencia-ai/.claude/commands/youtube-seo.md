# Comando: /youtube-seo

## Descripción
Crea título, descripción, tags y estructura SEO completa para un video de YouTube.

## Uso
```
/youtube-seo [tema del video]
/youtube-seo keyword=[keyword] tema=[descripción del video]
```

## Instrucción para Claude
Usa la skill `youtube-seo-description`. Crear: 2 opciones de título, descripción completa con keywords, timestamps, links, y lista de tags optimizados.
