# Comando: /automation-plan

## Descripción
Crea un plan completo de automatización de marketing para el cliente.

## Uso
```
/automation-plan
/automation-plan canal=[Meta Leads/Formulario/Email] objetivo=[calificar leads/nutrir/vender]
```

## Instrucción para Claude
Actúa como `marketing-automation-specialist`. Usar las skills `whatsapp-automation` y/o `n8n-workflow-designer` según aplique. Crear: trigger, flujo de mensajes, condiciones, integraciones y checklist de implementación.
