# Skill: YouTube Ads Campaign Builder

## Descripción
Crea campañas para YouTube Ads: formato de anuncio, script, segmentación, y KPIs.

## Formatos de YouTube Ads
- **Skippable In-Stream** — Se puede saltar a los 5 segundos, ideal para consideración/conversión
- **Non-Skippable** — 15-20 segundos, ideal para branding
- **Bumper Ads** — 6 segundos, ideal para reconocimiento
- **Video Discovery** — Aparece en resultados de búsqueda/sidebar

## Estructura del Script para Skippable Ad

Los primeros 5 segundos son críticos (antes del "skip"):
1. **Segundos 0-5:** Hook visual + audio impactante. NO poner logo.
2. **Segundos 5-15:** Problema o promesa que engancha
3. **Segundos 15-30:** Solución y prueba
4. **Segundos 30+:** CTA claro

## Formato de Salida

```
## CAMPAÑA YOUTUBE ADS — [Cliente]

**FORMATO:** [Skippable In-Stream]
**DURACIÓN:** [30 / 60 segundos]
**OBJETIVO:** [Leads / Tráfico / Reconocimiento]

### SCRIPT DEL ANUNCIO

**[00:00-00:05] HOOK (crítico — antes del skip)**
[Descripción de lo que se ve + Audio]

**[00:05-00:15] PROBLEMA/PROMESA**
[Texto del narrador o persona en cámara]

**[00:15-00:25] SOLUCIÓN**
[Presentar la solución con beneficios]

**[00:25-00:30] CTA**
[CTA claro con urgencia si aplica]

### SEGMENTACIÓN
- Demografía: [Edad, género]
- Intereses: [Categorías]
- Keywords de YouTube: [Lista]
- Canales de exclusión: [Categorías inapropiadas]
- Dispositivos: [Todos / Solo móvil]

### KPIs
- View Rate objetivo: [30%+]
- CPV objetivo: [$X]
- CTR objetivo: [X%]
```
