# Workflow: Google Ads Campaign

## Descripción
Proceso completo para crear campañas de Google Ads de alto rendimiento.

---

## PASO 1: Definir Objetivo y Tipo
- [ ] Objetivo: [Leads / Ventas / Tráfico]
- [ ] Tipo: [Search / Performance Max / Display / YouTube]
- [ ] Presupuesto diario
- [ ] Estrategia de puja: [Maximizar conversiones / CPA objetivo / ROAS objetivo]

## PASO 2: Investigar Keywords
Para campañas Search:
- [ ] Keywords de alta intención (compra, contratar, precio)
- [ ] Keywords de marca (nombre del cliente)
- [ ] Keywords de competidores (opcional)
- [ ] Keywords long-tail específicas
- [ ] Intención de cada keyword (informacional vs. transaccional)
- [ ] Volumen estimado y competencia

## PASO 3: Crear Estructura de Grupos de Anuncios
- [ ] 1 tema por grupo de anuncios
- [ ] 10-20 keywords por grupo máximo
- [ ] Nombre descriptivo por grupo
- [ ] Keyword principal del grupo en el nombre

## PASO 4: Crear Copy de Anuncios (RSA)
Para cada grupo:
- [ ] 15 headlines (incluir keyword en al menos 3-5)
- [ ] 4 descriptions (beneficios + CTA)
- [ ] Al menos 1 anuncio RSA completo por grupo

## PASO 5: Crear Extensiones
- [ ] Sitelinks (4-6 con descripción)
- [ ] Callouts (6-8 frases de beneficio)
- [ ] Structured Snippets (categoría relevante)
- [ ] Call extension (número de teléfono)
- [ ] Location extension (si es negocio local)

## PASO 6: Revisar Landing Page
- [ ] Landing page relevante para cada grupo/keyword
- [ ] Mensaje coherente con el anuncio
- [ ] CTA claro y rápido
- [ ] Velocidad de carga aceptable

## PASO 7: Crear Negative Keywords Iniciales
Categorías a excluir:
- [ ] Términos de información/educación ("qué es", "cómo funciona")
- [ ] Términos irrelevantes de la industria
- [ ] Nombres de competidores (si no se quiere aparecer)
- [ ] Términos de trabajo ("trabajo de", "empleo como")
- [ ] Términos gratuitos ("gratis", "free", "curso gratuito")

## PASO 8: Definir KPIs y Período de Evaluación
- [ ] KPI principal: CPA objetivo = $X
- [ ] CTR mínimo esperado: X%
- [ ] Quality Score mínimo: 7+
- [ ] Período de evaluación: 2-4 semanas

## PASO 9: Plan de Optimización Post-Lanzamiento
- Semana 1: Monitorear search terms, excluir irrelevantes
- Semana 2: Evaluar CTR por anuncio, pausar los más bajos
- Mes 1: Ajustar bids por keyword según CPA
- Mes 2: Expandir keywords ganadoras, crear nuevos grupos

## Agentes Involucrados
- google-ads-specialist (líder)
- copywriter (copy de anuncios)
- landing-page-cro-specialist (revisión de landing)
