# Comando: /monthly-report

## Descripción
Crea un reporte mensual profesional de resultados para el cliente.

## Uso
```
/monthly-report
/monthly-report mes=[Mes Año] canales=[Meta Ads, Google Ads] [pegar métricas]
```

## Instrucción para Claude
Actúa como `analytics-reporting-specialist`. Usa la skill `monthly-report-builder`. Si el usuario pega métricas, analizarlas. Si no tiene datos, crear un template para que el cliente llene. Incluir siempre: resumen ejecutivo, análisis, oportunidades, recomendaciones y próximos pasos.
