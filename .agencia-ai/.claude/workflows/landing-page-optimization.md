# Workflow: Landing Page Optimization

## Descripción
Proceso completo para revisar y optimizar una landing page para maximizar conversiones.

---

## PASO 1: Establecer Baseline
- [ ] URL de la landing page
- [ ] Objetivo actual (leads / ventas / registros)
- [ ] Tasa de conversión actual (si se tiene)
- [ ] Fuente de tráfico principal
- [ ] Dispositivo más usado por la audiencia (móvil vs. desktop)

## PASO 2: Revisar Headline (Above the Fold)
Evaluar el headline principal:
- [ ] ¿Comunica el beneficio principal en <10 palabras?
- [ ] ¿Está orientado al cliente (no a la empresa)?
- [ ] ¿Es específico o genérico?
- [ ] Puntuación: [1-10]
- Versión optimizada propuesta: [Nueva versión]

## PASO 3: Revisar Propuesta de Valor
- [ ] ¿Se entiende qué es, para quién es y qué se gana?
- [ ] ¿Es diferente de los competidores?
- [ ] ¿Está ubicada above the fold?
- Versión optimizada: [Nueva versión]

## PASO 4: Revisar Above the Fold Completo
Elementos presentes y su calidad:
- [ ] Headline: [Análisis]
- [ ] Subheadline: [Análisis]
- [ ] CTA principal: [Análisis]
- [ ] Imagen/video: [Análisis]
- [ ] Señal de confianza: [Análisis]

## PASO 5: Revisar CTA Principal
- [ ] ¿Es específico y orientado al beneficio?
- [ ] ¿Contrasta visualmente?
- [ ] ¿Está repetido en el scroll?
- Versión optimizada: ["Texto optimizado del botón"]

## PASO 6: Revisar Formulario
- [ ] ¿Cuántos campos tiene? (objetivo: mínimo necesario)
- [ ] ¿Los campos son necesarios todos?
- [ ] ¿El CTA del botón del form es específico?
- [ ] ¿Hay mensaje de privacidad debajo?
- Recomendación: [Reducir a X campos — cuáles mantener]

## PASO 7: Revisar Objeciones y Prueba Social
- [ ] ¿Se abordan las principales objeciones en la página?
- [ ] Testimonios presentes: [Sí/No/Cantidad]
- [ ] ¿Tienen nombre, foto y resultado específico?
- [ ] ¿Hay garantía o reducción de riesgo?

## PASO 8: Revisar Estructura Móvil
Verificar en móvil:
- [ ] ¿El CTA es visible sin hacer scroll?
- [ ] ¿El texto es legible sin zoom?
- [ ] ¿Los botones son fáciles de tocar?
- [ ] ¿El formulario funciona bien?

## PASO 9: Crear Versión Optimizada del Copy
Usar skill `landing-page-copy/SKILL.md` para crear:
- [ ] Nuevo headline
- [ ] Nuevo subheadline
- [ ] Nueva sección de beneficios
- [ ] Nuevos testimonios (formato sugerido)
- [ ] Nuevo CTA

## PASO 10: Crear Hipótesis para A/B Test
Priorizar 2-3 tests basados en el análisis:
1. Test 1: [Headline A vs B] — Hipótesis: [X mejorará conversión porque Y]
2. Test 2: [CTA A vs B]
3. Test 3: [Con/sin video]
