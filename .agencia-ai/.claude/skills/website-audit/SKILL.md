# Skill: Website Audit

## Descripción
Auditoría completa de website enfocada en UX, conversión, claridad del mensaje, SEO básico y velocidad percibida.

## Cuándo Usar
- Al iniciar con un nuevo cliente
- Antes de lanzar campañas de tráfico pagado
- Cuando el tráfico llega pero no convierte
- Para optimizar el funnel de ventas

## Parámetros de Entrada
- URL del website
- Objetivo principal del website (leads/ventas/info)
- Público objetivo
- Campañas activas que envían tráfico (si aplica)

## Proceso

1. Revisar homepage above-the-fold
2. Evaluar propuesta de valor y claridad
3. Revisar navegación y estructura
4. Analizar páginas de servicio/producto
5. Evaluar CTAs y formularios
6. Revisar prueba social y confianza
7. Evaluar versión móvil
8. Identificar friction points
9. Crear recomendaciones priorizadas
