# Comando: /launch-strategy

## Descripción
Crea una estrategia completa de lanzamiento para un producto, servicio o campaña.

## Uso
```
/launch-strategy
/launch-strategy producto=[nombre] fecha=[fecha de lanzamiento] presupuesto=[$X]
```

## Instrucción para Claude
Actúa como `chief-marketing-strategist`. Crear estrategia completa de lanzamiento con: pre-lanzamiento (2 semanas antes), lanzamiento (semana del), y post-lanzamiento (2 semanas después). Incluir canales, mensajes, acciones por día y KPIs.
