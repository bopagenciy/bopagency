# Skill: Reel Script Generator

## Descripción
Crea scripts completos para reels de 15, 30 y 60 segundos con hook, desarrollo, CTA, caption y hashtags.

## Parámetros de Entrada
- Cliente y servicio a promover
- Duración: [15 / 30 / 60 segundos]
- Objetivo: [Awareness / Engagement / Leads / Ventas]
- Ángulo o tema del reel
- Tono: [Educativo / Entretenimiento / Emocional / Tutorial]

## Formato de Salida

```
## SCRIPT DE REEL — [Cliente]
**Duración:** [30 segundos] | **Objetivo:** [Leads]

### CAPTION
[Caption completo listo para publicar]

### HOOK VISUAL (Frame 0-1 seg)
[Lo primero que se ve — tiene que parar el scroll]

### SCRIPT
**[00:00-00:03] HOOK**
Texto en pantalla: "[Frase de impacto]"
Audio/Voz: "[Lo que se dice o sugiere como música]"

**[00:03-00:15] DESARROLLO**
Texto en pantalla: "[Punto 1]"
Audio: "[Explicación breve]"

Texto en pantalla: "[Punto 2]"
Audio: "[Explicación breve]"

**[00:15-00:25] PRUEBA/EJEMPLO**
Texto en pantalla: "[Dato o ejemplo concreto]"
Audio: "[Refuerzo de la idea]"

**[00:25-00:30] CTA**
Texto en pantalla: "[Llamada a la acción]"
Audio: "[CTA hablado]"

### SUGERENCIAS DE PRODUCCIÓN
- Música: [Tipo de música / estilo]
- Transiciones: [Rápidas / Suaves]
- Texto en pantalla: [Color, tamaño sugerido]
- Toma inicial: [Descripción de cómo empezar]

### HASHTAGS
[#hash1 #hash2 ... #hash20]
```

## Ejemplos de Hooks que Funcionan

15 seg: Hook directo, problema + solución
30 seg: Hook + problema + solución + CTA
60 seg: Hook + historia + prueba + solución + CTA
