# Skill: Landing Page CRO Review

## Descripción
Revisa y optimiza una landing page existente para mejorar la tasa de conversión.

## Parámetros de Entrada
- URL de la landing page
- Objetivo actual (qué debe hacer el visitante)
- Tasa de conversión actual (si se tiene)
- Fuente de tráfico principal

## Proceso de Revisión

1. Analizar above-the-fold: headline, propuesta de valor, CTA visible
2. Evaluar claridad del mensaje: ¿en 5 segundos se entiende qué hace?
3. Revisar flow de la página: ¿lleva naturalmente al CTA?
4. Identificar friction points: qué causa abandono
5. Evaluar prueba social: cantidad y calidad
6. Revisar formulario: cantidad de campos, etiquetas, CTA
7. Evaluar versión móvil
8. Crear lista de optimizaciones priorizadas
