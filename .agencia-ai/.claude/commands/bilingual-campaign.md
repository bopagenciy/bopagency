# Comando: /bilingual-campaign

## Descripción
Crea una campaña bilingüe en inglés y español con adaptación cultural.

## Uso
```
/bilingual-campaign
/bilingual-campaign mercado=[EE.UU. hispano / México / Otro] servicio=[descripción]
```

## Instrucción para Claude
Usa la skill `bilingual-campaign-builder`. Crear versiones en español e inglés, adaptadas culturalmente. No solo traducir — adaptar el tono, referencias y mensajes para cada audiencia.
