# Workflow: Website Audit

## Descripción
Auditoría completa y sistemática de un website con recomendaciones priorizadas de mejora.

## Duración Estimada
1-2 horas

---

## PASO 1: Información Inicial
- URL del website
- Objetivo principal (leads / ventas / información)
- Fuente principal de tráfico
- Tasa de conversión actual (si se tiene)

## PASO 2: Revisar Homepage Above the Fold
Evaluar lo que se ve SIN hacer scroll:
- [ ] ¿Qué ofrece la empresa? (¿claro en 5 segundos?)
- [ ] ¿Headline claro y orientado al beneficio?
- [ ] ¿CTA visible y específico?
- [ ] ¿Imagen/video relevante al servicio?
- [ ] ¿Señal de confianza visible?

## PASO 3: Evaluar Propuesta de Valor
- [ ] ¿Diferencia del resto de competidores?
- [ ] ¿Orientada al cliente (qué gana él) vs. a la empresa (quiénes somos)?
- [ ] ¿Específica o genérica?
- [ ] Puntuación: [1-10]

## PASO 4: Revisar Navegación y Estructura
- [ ] ¿Menos de 7 elementos en el menú?
- [ ] ¿Hay ruta clara hacia la conversión?
- [ ] ¿Las páginas más importantes están en el menú?
- [ ] ¿Hay breadcrumbs donde aplica?

## PASO 5: Analizar Páginas de Servicios/Productos
Para cada página de servicio:
- [ ] Headline que comunica el beneficio
- [ ] Descripción clara de qué es y cómo funciona
- [ ] Para quién es (y para quién NO es)
- [ ] CTA claro con siguiente paso
- [ ] Precio o guía de precio (si aplica)

## PASO 6: Evaluar CTAs
- [ ] ¿Cuántos CTAs hay? (ideal: 1 principal + CTAs de soporte)
- [ ] ¿Son específicos? ("Agenda tu consulta" vs. "Click aquí")
- [ ] ¿Están en posiciones estratégicas?
- [ ] ¿Color que contraste con el fondo?

## PASO 7: Revisar Prueba Social
- [ ] Testimonios (cantidad y calidad — con nombre y foto es mejor)
- [ ] Casos de éxito con resultados
- [ ] Logos de clientes (si B2B)
- [ ] Calificaciones de Google / Yelp
- [ ] Números de impacto ("500+ clientes", "5 años de experiencia")

## PASO 8: Evaluar Contenido
- [ ] ¿El copy habla de beneficios o solo de features?
- [ ] ¿Hay jerga técnica innecesaria?
- [ ] ¿Hay errores de ortografía o gramática?
- [ ] ¿El tono coincide con la audiencia objetivo?

## PASO 9: Revisar Velocidad Percibida y Móvil
- [ ] ¿La página carga rápido visualmente?
- [ ] ¿El sitio es responsive?
- [ ] ¿El CTA es visible en móvil sin hacer scroll?
- [ ] ¿El formulario funciona en móvil?
- [ ] ¿El texto es legible sin zoom?

## PASO 10: Crear Recomendaciones Priorizadas

Categorizar por:
- 🔴 Crítico (afecta conversiones directamente — hacer en 1 semana)
- 🟡 Importante (mejora significativa — hacer este mes)
- 🟢 Nice to have (optimización — hacer cuando haya tiempo)

---

## ENTREGABLE FINAL
Usar formato de `templates/auditoria-website.md` o skill `website-audit/SKILL.md`

## Agentes Involucrados
- landing-page-cro-specialist (líder)
- seo-aeo-geo-specialist (SEO básico)
- copywriter (evaluación de copy)
