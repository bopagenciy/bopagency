# Skill: Social Media Calendar

## Descripción
Crea calendarios de contenido mensual completos con ideas, hooks, captions, hashtags y formatos para cada plataforma.

## Parámetros de Entrada
- Cliente: [nombre]
- Mes y año
- Plataformas: [Instagram / TikTok / Facebook / LinkedIn / YouTube Shorts]
- Frecuencia por plataforma
- Objetivos del mes
- Eventos o fechas especiales del cliente

## Formato de Salida

```
## CALENDARIO DE CONTENIDO — [Cliente]
**Mes:** [Mes Año] | **Plataformas:** [Lista]

### OBJETIVOS DEL MES
1. [Objetivo 1]
2. [Objetivo 2]
3. [Objetivo 3]

### PILARES DE CONTENIDO
1. 🎓 Educativo (X posts)
2. 💡 Inspiracional (X posts)
3. 😄 Entretenimiento (X posts)
4. ⭐ Prueba Social (X posts)
5. 🎯 Conversión (X posts)

### SEMANA 1 — [Fechas]

**Lunes [fecha]**
- Plataforma: Instagram Feed
- Pilar: Educativo
- Idea: [Descripción del post]
- Hook: [Primera línea]
- Caption: [Caption completo]
- Formato: [Carrusel / Reel / Imagen]
- Hashtags: [#hash1 #hash2 #hash3]
- CTA: [Acción que se pide]
- Idea visual: [Descripción de lo que se ve]

[Repetir para cada día/post de la semana]

### SEMANA 2 — [Fechas]
[...]

### SEMANA 3 — [Fechas]
[...]

### SEMANA 4 — [Fechas]
[...]

### FECHAS ESPECIALES DEL MES
- [Fecha]: [Evento/Conmemoración] — Idea de contenido

### HASHTAG SETS RECOMENDADOS
**Set General:** [#hash1 ... #hash30]
**Set Niche:** [#hash1 ... #hash15]
**Set Branded:** [#marcacliente #servicio]
```
